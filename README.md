# Hamza Rafique portfolio

**Open `Hamza-Rafique-Portfolio-Standalone-Verified.html` directly after extracting this ZIP.** Images, scripts, and the software-rendered 3D-style fallback are embedded in that one file. It works without Node.js or a server.

The site also includes real WebGL animation when the browser supports it. When WebGL is unavailable, the animated Canvas fallback appears automatically. System reduced-motion settings intentionally pause 3D animation.

Editable source files are in `dist/`. Keep the folder structure intact when modifying them. Published Site source: version 9.
